# 2026 第十二屆感恩與傳承

中華國際財經創意交流協會獎學金暨文藝獎活動網站。

## 架構

- `site/`：公開活動介紹、獎項導覽與申請入口。
- Google Apps Script：線上申請與附件收件；管理表與附件保持私人。
- GitHub Pages：只發布 `site/`；不儲存申請名冊、附件、密碼或存取權杖。

網站發布與開放收件是兩件事。收件時間、規則核定與資料使用告知仍由主辦者確認，部署不會自行變更。

## 發布

首次發布流程會從本活動已公開的 Google 網頁取得同一份前端程式和公告文件，核對文件 SHA-256，保存成可編輯的 `site/` 原始碼。之後直接修改 `site/` 並提交，由 GitHub Actions 更新 Pages。
