# 2026 第十二屆感恩與傳承

中華國際財經創意交流協會獎學金暨文藝獎活動網站。

**公開網站：https://gentleowl-er.github.io/sibia-gratitude-2026/**

## 架構

- `site/index.html`：活動介紹、重要日程、申請流程、常見問題及聯絡方式。
- `site/catalog.js`：16 類獎項摘要與原簡章章節依據。
- `site/app.js`：獎項搜尋、分類、詳細說明與多選帶入 Google 申請。
- `site/style.css`：桌機及手機版型、鍵盤焦點、降低動態效果支援。
- Google Apps Script：既有的完整線上申請與附件收件介面。名冊與附件的目的地為主辦者私人 Google Drive，不放進 GitHub。
- `.github/workflows/pages.yml`：檢查 JavaScript、獎項完整性與公開檔案後，只將 `site/` 發布到 GitHub Pages。

## 發布與收件是兩件事

活動首頁已完成 GitHub Actions 發布。Google 申請入口已連結，但連結存在不代表後端完成初始化、已開放收件，或寄信與上傳已通過實際驗收。最新收件狀態以 Google 申請頁顯示為準。

部署不會代主辦者核定截止時間、收件規則或資料使用告知，也不會自行開啟收件。未開放前，請勿輸入真實個資或以示範操作當作正式報名。

## 維護

修改 `site/` 內的原始碼並提交到 `main`，GitHub Actions 會驗證及更新網站。可以在 Actions 查看每次實際發布結果。網站不需要第三方分析追蹤，不在公開頁面直接蒐集申請資料。

原始 Word 簡章仍由既有 Google 活動頁提供下載；公開首頁的「完整簡章與表格」會開啟該下載入口。
